# 3D models and aircraft type data

## Aircraft types

`public/data/aircraft-types.json` holds all 2788 ICAO Doc 8643 type designators (name, description code, wake category), taken from the mirror in [wiedehopf/tar1090-db](https://github.com/wiedehopf/tar1090-db). `tools/build-types.mjs` builds it and sorts each type into a generic class.

The app picks a model in this order:

1. the model listed for the exact ICAO type, if there is one;
2. otherwise the generic model for the type's class;
3. otherwise (no flight plan, or a type that isn't in Doc 8643) the `unknown` model.

## Models

All aircraft models come from the [FlightGear](https://www.flightgear.org/) aircraft repositories and are licensed under the **GNU GPL v2** (full text in [public/models/LICENSE-GPL-2.0.txt](public/models/LICENSE-GPL-2.0.txt)). They reached this project in three ways:

- already converted to glTF 1.0 by [Flightradar24/fr24-3d-models](https://github.com/Flightradar24/fr24-3d-models), then upgraded to glTF 2.0 by `tools/upgrade-gltf1.mjs`;
- already in glTF 2.0 from [Ysurac/FlightAirMap-3dmodels](https://github.com/Ysurac/FlightAirMap-3dmodels);
- converted from FlightGear AC3D files by `tools/ac3d-to-glb.mjs`. Cockpit interiors and animation-only parts were dropped. The F-16 is drawn in flat grey because its skin is an SGI .rgb texture, which browsers can't display.

The weather balloon is generated by `tools/make-weather-balloon.mjs`.

`tools/normalize-models.mjs` processes every model the same way: it rotates it so +Y is the nose and +Z is up, keeps it at real size in metres (it rescales any that aren't), puts the origin under the aircraft, removes animations, and caps textures at 512 px.

## Rebuilding

```bash
npm install
node tools/build-types.mjs
# put the downloads in models/raw/ (see the sources above and models/sources.json)
node tools/upgrade-gltf1.mjs models/raw/fr24 models/raw/fr24-v2
node tools/ac3d-to-glb.mjs models/raw/fg/ch47.ac models/raw/fg-v2/ch47.glb --exclude "Cockpit|panel|toggle|CDU|RadAlt|lever|FirePull|glareshield|Cargohold|inner|OHpanel|Panel"
node tools/ac3d-to-glb.mjs models/raw/fg/f16.ac models/raw/fg-v2/f16.glb --exclude "Chute|Light|Spinning|Tailroot|Protector|Flash|Formation|Station|Fan$|Turbine|Internal|Box" --flat-color 0.55,0.59,0.62
node tools/make-weather-balloon.mjs models/raw/gen/weather-balloon.glb
node tools/normalize-models.mjs
```
